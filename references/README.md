# Raw references

This folder is the project inbox for screenshots, sketches, links, colors, assets, competitor examples, and unstructured notes.

Rules:

- Messy input is expected; the user should not have to pre-classify it.
- Before committing a reference, check it for credentials, personal/customer data, private URLs, or other sensitive material.
- References are evidence/inspiration, not permission to copy protected branding/assets or import another product's design wholesale.
- Extract what is relevant (for example navigation density or table hierarchy) into durable product/UI decisions; do not infer that every visual property should be copied.
- Keep original non-sensitive references when they help future agents understand the source material.
- Product truth belongs in `docs/`, not in this inbox.
